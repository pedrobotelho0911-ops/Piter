# 03 — Meta Ad Library FR — Verão 2026

**Confiança: BAIXA (não obtido automaticamente)**

A Meta Ad Library exige interface JS/login para filtrar "anúncios ativos há +30 dias",
não acessível neste ambiente. Abaixo, o protocolo exato para você rodar no seu Chrome
em ~20 min — é o sinal mais forte de lucratividade que existe.

## Protocolo manual (faça isto)
1. `https://www.facebook.com/ads/library/` → País: **France** · Categoria: Tous les annonces.
2. Buscar, um a um:
   `anti moustique` · `ventilateur portable` · `jambes lourdes` · `anti taches` ·
   `oreiller rafraîchissant` · `anti cellulite` · `crème solaire visage`.
3. Para cada termo, priorize anunciantes com:
   - **Anúncio ativo há +30 dias** (sinal: está pagando = está lucrando).
   - **+5 variações de criativo** (sinal: estão escalando/testando = produto validado).
4. Clique na URL de destino e registre: plataforma (Shopify?), preço, nº de avaliações,
   prazo de envio prometido.

## O que isso decide
- Produto com **vários anunciantes há +30 dias** = mercado quente e provado → entre com
  ângulo/criativo diferente, não preço.
- Produto com **zero anúncios ativos** = ou é cedo (oportunidade) ou não converte no pago
  (risco) → valide primeiro no orgânico (que é o plano de qualquer forma).

# Premium Deliverables — Padrão de qualidade para todo entregável

Esta skill não substitui as skills de formato (docx, xlsx, pptx, pdf) — ela define o padrão de qualidade que TODO entregável produzido com elas deve atingir.

## Princípios universais
1. **Conclusão primeiro.** Todo documento abre com o resultado/recomendação em 3–5 linhas (sumário executivo). Detalhe vem depois, para quem quiser.
2. **Um documento = uma decisão.** Antes de produzir, responder: que decisão ou ação este entregável habilita? Tudo que não serve a isso, cortar.
3. **Números com contexto.** Nunca apresentar um número sozinho — sempre com comparação (vs período anterior, vs meta, vs benchmark) e implicação ("o que isso muda").
4. **Idioma**: português impecável, sem anglicismo desnecessário; termos técnicos consagrados podem ficar em inglês.

## Padrões por formato
### Documentos (Word/PDF)
- Estrutura: capa → sumário executivo → corpo com headings navegáveis → próximos passos com responsável e prazo
- Tipografia: uma família só, hierarquia clara (título/heading/corpo), sem sublinhado decorativo
- Parágrafos ≤ 4 linhas; usar bullets quando enumerar

### Planilhas (Excel)
- Aba 1 = dashboard/resumo com os números-chave; dados crus em abas separadas
- Fórmulas, nunca valores colados (o usuário vai atualizar depois)
- Formatação: cabeçalhos destacados, números com separador de milhar, moeda em R$, formatação condicional nos KPIs
- Congelar painéis no cabeçalho; nomear abas pelo conteúdo

### Apresentações (PowerPoint)
- 1 slide = 1 ideia; título do slide é a conclusão ("Receita cresceu 32% puxada por X"), não o tema ("Receita")
- Máximo ~30 palavras por slide; detalhe vai para notas do apresentador
- Paleta consistente (2 cores + neutros); gráficos seguem a skill `dataviz` quando disponível

### Relatórios recorrentes
- Mesmo layout toda edição (comparabilidade > criatividade)
- Seção fixa "Decisões necessárias" no topo

## Checklist final (antes de entregar qualquer arquivo)
- [ ] Sumário executivo com conclusão em 3–5 linhas
- [ ] Todo número tem comparação e implicação
- [ ] Zero placeholder/lorem/valor de exemplo esquecido
- [ ] Nomes de arquivo descritivos com data: `relatorio-vendas-2026-07.xlsx`
- [ ] Revisão de português concluída
- [ ] Próximos passos acionáveis no fechamento

# Piter — Memória do Projeto

## Perfil e contexto
- Usuário: Pedro (pedrobotelho0911@gmail.com), Brasil. Comunicação em **português**.
- Ecossistema conectado: **Remotion** (este repo), **Higgsfield** (geração de vídeo/imagem/áudio com IA, Shorts Studio, Virality Predictor), **Shopify** (e-commerce), **GitHub**.
- Objetivo macro: acelerar crescimento em criação de conteúdo (vídeo/short-form), mídia gerada por IA e e-commerce — com qualidade de nível premium em tudo que for entregue.

## Setores de atuação identificados
1. **Vídeo programático** — Remotion/React/TypeScript (este repositório).
2. **Conteúdo viral short-form** — TikTok/Reels/Shorts via Higgsfield Shorts Studio + Virality Predictor.
3. **Mídia gerada por IA** — imagens, vídeos, áudio, voz, 3D via Higgsfield.
4. **E-commerce** — operação e crescimento de loja Shopify (produtos, coleções, descontos, analytics).
5. **Conteúdo → Comércio** — vídeos de produto, ads e criativos que convertem para a loja.

## Skills premium deste projeto (`.claude/skills/`)
| Skill | Quando usar |
|---|---|
| `remotion-pro` | Qualquer vídeo/composição/animação neste repo Remotion |
| `viral-shorts` | Criar shorts/reels/TikToks, analisar ou maximizar viralidade |
| `ai-media-studio` | Gerar ou editar imagem/vídeo/áudio/voz/3D com Higgsfield |
| `shopify-growth` | Gerenciar/analisar/crescer a loja Shopify |
| `content-to-commerce` | Criativos de produto, ads em vídeo, campanhas que vendem |
| `premium-deliverables` | Elevar qualquer entregável (docs, planilhas, decks, PDFs, relatórios) a padrão premium |

## Convenções do projeto
- Stack: Remotion 4 + React 19 + TypeScript 5 + Tailwind v4 + Zod.
- Antes de commitar código: `npm run lint` (ESLint + tsc).
- Formatos padrão de vídeo: vertical 1080×1920 (shorts), horizontal 1920×1080 (YouTube), quadrado 1080×1080 (feed).
- Composições registradas em `src/Root.tsx`; cada vídeo em sua própria pasta em `src/`.
- Respostas e documentação para o usuário: sempre em português; código e nomes de variáveis em inglês.
